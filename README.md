# socialcare

A new Flutter project.

## Getting Started

SocialCare – Smart Care System with Disease Prediction

SocialCare is a mobile and web-based humanitarian support platform designed to connect people in need with volunteers and service providers.
The system helps users submit and track requests, enables volunteers to respond to verified requests, and provides administrators with tools to monitor and coordinate the overall system. It also includes disease prediction and priority-based request management.

##🎯 Objectives
Identify and track real-time needs and emergencies.
Prioritize user requests.
Connect individuals, NGOs, donors, and volunteers through one platform.
Support transparent, timely, and accountable aid delivery.

##👥 Modules

###👤 User Module
The User module allows people to request assistance and manage their requests.

Features:

User registration and login
Submit assistance requests
Medical, economic, child, elderly, and social emergency requests
Emergency alerts
Request status tracking
Volunteer viewing
Chat with volunteers
Profile management
Feedback and ratings
Disease prediction using Random Forest

###🤝 Volunteer Module

The Volunteer module allows volunteers to respond to verified requests.

Features:

Volunteer registration and login
View verified emergency requests
Accept or reject requests
Availability-based support
Chat with users
View approved requests
Manage volunteer profile

###🛠️ Admin Module

The Admin module provides centralized monitoring and management.

Features:

Admin authentication
Verify and monitor requests
Prioritize emergency requests
Monitor volunteer activities
Monitor emergency alerts
Oversee aid distribution and donations
Manage the overall platform

##Disease Prediction
The system includes a disease-prediction feature based on user-provided symptoms. The project documentation specifies Random Forest for disease prediction.
